# Painting References

Local reference images used by Painting Fragment mode.

- `van-gogh.jpg`: Vincent van Gogh, *Irises*, The Metropolitan Museum of Art public domain image.
- `monet.jpg`: Claude Monet, *Water Lilies (Agapanthus)*, Cleveland Museum of Art open access CC0 image.
- `vermeer.jpg`: Johannes Vermeer, *Young Woman with a Lute*, The Metropolitan Museum of Art public domain image.
- `klimt.jpg`: Gustav Klimt, *Hermine Gallia*, Cleveland Museum of Art open access CC0 image.

The app loads these files from `/paintings/{source}.jpg`.
